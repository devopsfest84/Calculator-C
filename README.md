# Calculator-C

A simple command-line calculator program written in C.

## Features

* Addition (`+`)
* Subtraction (`-`)
* Multiplication (`*`)
* Division (`/`)
* Displays the final result using `=`
* Option to start a new calculation
* Quit option (`q`)
* Prevents division by zero
* Handles invalid number input

## Requirements

* C compiler such as GCC
* Windows, Linux, or another operating system with a C compiler

## How to Run

Compile the program:

```bash
gcc BasicCalculator.c -o BasicCalculator
```

Run the program:

```bash
./BasicCalculator
```

On Windows:

```bash
BasicCalculator.exe
```

## Project File

* `BasicCalculator.c` — Main C source code for the calculator.
